# E.Sangeetha-7582973

This repository contains practical exercises and projects developed using HTML, CSS, JavaScript, ANSI SQL with MySQL, and Core Java. HTML is used to structure web pages, CSS enhances their design and responsiveness, and JavaScript adds interactivity and dynamic functionality. ANSI SQL with MySQL is used for creating, managing, and querying databases, enabling efficient data storage and retrieval. Core Java focuses on object-oriented programming concepts, exception handling, collections, file handling, and other fundamental programming techniques. Together, these technologies provide a strong foundation in web development, database management, and software application development while improving problem-solving and programming skills through hands-on practice.
